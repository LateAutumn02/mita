# mita v0.1.6

This Windows release updates the bundled literature extraction skill.

## Literature extraction

- Rewrote the bundled `literature-field-extraction` skill in Chinese.
- Kept tool names and schema keys such as `PDFExtract`, `LiteratureExcel`, `ToolSearch`, `records`, and `issues` unchanged so the agent can still call tools correctly.
- Preserved the Windows-first workflow, topic-based Excel naming, final cleanup requirements, and no-OCR warning.
- Added stricter PDFExtract limits: each PDF must run a fast text-layer preflight, scanned/image-only PDFs should be marked quickly, and stalled shards should be stopped and retried only once instead of waiting indefinitely.

## Packaging

- Desktop release artifacts are Windows-only for this build.
