# mita v0.1.3

本次版本主要修复干净 Windows 环境中安装后首次使用遇到的运行时问题，让桌面版更适合直接发给普通用户测试。

## 更新内容

- Windows 下 `Bash` 工具不再强制依赖 Git Bash；打包版会自动使用 PowerShell 后端执行命令。
- `Glob` / `Grep` 在找不到 ripgrep 时会自动退回内置文件扫描与搜索逻辑，避免因为缺少 `rg` 导致目录扫描失败。
- 使用第三方服务商或自定义 API 地址时，API Key 错误提示改为引导用户到「设置 > 服务商」配置，而不是误提示 `/login`。
- API 连接被拒绝或域名无法解析时，会显示更明确的服务商地址、代理、网络检查提示。
- Windows 未安装 Python 时，不再自动注册 Computer Use MCP 工具，避免启动后出现 Python venv 创建失败；文献提取等核心流程不依赖该工具。

## 说明

Computer Use 的鼠标、截图、应用控制类能力仍需要 Python 辅助运行时。当前版本会在缺少 Python 的 Windows 环境中跳过这组工具，避免影响主要对话、文件读写、目录扫描和文献提取工作流。
