# mita v0.2.1

从 mita v0.1.x 系列重构而来：**不再修改 cc-haha 源码**，改为通过 Electron 首次启动自动 seed 内置 skill + MCP server。

## 核心变化

- **零源码侵入**：完全不修改 `src/` 目录。cc-haha 上游源码保持纯净，rebase 零冲突。
- **自动 seed**：Electron `app.whenReady()` 时自动把 skill 和 MCP server 二进制安装到 `~/.claude/`，用户零配置。
- **MCP server 架构**：`PDFExtractTool` 和 `LiteratureExcelTool` 的业务逻辑（原 mita 分支已验证稳定）原样搬运到独立 MCP server，依赖（`pdfjs-dist` / `exceljs`）通过 `bun build --compile` 静态链接进单文件二进制。

## 安装说明

### Windows

1. 下载 `Claude-Code-Haha-0.2.1-win-x64.exe`
2. 首次安装可能触发 SmartScreen 警告（未签名），点"仍要运行"
3. 启动后自动 seed：
   - `~/.claude/skills/literature-field-extraction/`（SKILL.md + references）
   - `~/.claude/mita/bin/mita-mcp-server.exe`（100MB 单文件二进制）
   - `~/.claude/.claude.json` 注册 `mcpServers.literature`（stdio）
4. 配置模型 provider + API Key 后即可使用

### 使用

对 agent 说"用 literature-field-extraction skill 处理这两个目录的 PDF 生成 excel"，agent 会：
1. 调用 `literature-field-extraction` skill 启动工作流
2. 调用 `mcp__literature__PDFExtract` 读取 PDF 文本层
3. 调用 `mcp__literature__LiteratureExcel` 合并 JSON 生成 .xlsx

## 技术细节

- skill 从 `src/skills/bundled/literature-field-extraction/`（原 mita 分支）原样搬到 `mita-dist/skills/`
- MCP server 两个 tool 带 `_meta: { 'anthropic/alwaysLoad': true }`，避免 cc-haha 的 deferred-tools 机制导致某些模型（如 DeepSeek）不调用
- seed 逻辑幂等（按 `~/.claude/mita/VERSION` 判断），升级时改版本号自动 re-seed
- 保留 `~/.claude.json` 已有字段，只追加 `mcpServers.literature`

## 已知限制

- 仅 Windows x64 预编译二进制；macOS / Linux 需在对应平台编译
- MCP server 二进制约 100MB（pdfjs + exceljs 静态链接），增大安装包体积
- 未签名，首次安装需手动放行 SmartScreen
