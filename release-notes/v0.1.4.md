# mita v0.1.4

本次版本聚焦文献字段提取 skill 的收尾效率，以及 Windows-only 快速打包。

## 更新内容

- 文献字段提取 skill 增加最终校验限制：默认由主 agent 检查最终 Excel，不再默认启动额外验证子 agent。
- 最终校验优先基于 shard JSON、issues、最终 Excel 和字段说明书执行，避免为了验证而重新全量读取所有 PDF。
- 只有发现具体可疑字段、冲突、缺失证据，或用户明确要求抽查时，才回读对应 PDF 或进行 Web 核验。
- 桌面 release workflow 改为仅构建 Windows x64 安装包，跳过 macOS 构建以缩短打包时间。
- 仓库加入 `案例.zip` 示例资料包。

## 说明

本版本不改变 OCR 策略。扫描件/纯图片 PDF 仍会按当前 workflow 记录 issue，并将无法核验字段留空。
