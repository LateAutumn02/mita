# mita v0.1.5

This Windows release focuses on safer desktop updates and a cleaner literature extraction workflow.

## Fixes

- Fixed the manual update flow where the renderer could show an available update while the Electron updater no longer had a native pending update to download.
- The update button now downloads first and only installs after the update is fully downloaded.
- Added an install guard so a failed or stale download cannot enter the install/restart phase.

## Literature extraction

- The bundled literature extraction skill now treats Windows as the default user environment.
- Final Excel files must use predictable topic-based names instead of temporary names such as `f1.xlsx`.
- The main agent must remove generated byproducts before delivery, keeping only the final Excel workbook(s) and the user's original inputs.

## Packaging

- Desktop release artifacts are Windows-only for this build.
