# Claude Code Haha v0.1.0

This is the first public test release for the `mita` repository.

## Highlights

- Includes the generic literature field extraction skill.
- Includes `PDFExtract` for bounded PDF text extraction.
- Includes `LiteratureExcel` for merging JSON extraction shards into Excel.
- Configures desktop auto-update to read releases from `LateAutumn02/mita`.

## Notes

- Scanned/image-only PDFs are not handled yet. The extraction workflow should warn users before processing and leave unverifiable fields blank.
- Windows builds are unsigned, so Windows may show a SmartScreen warning on first install.
