# mita v0.1.2

本版本优化文献字段提取工作流，主要面向批量 PDF 文献生成 Excel 的场景。

## 更新内容

- 优化 `literature-field-extraction` 内置 skill。
- 子 agent 调度改为最多 5 个并行，每个子 agent 最多处理 3 个 PDF。
- 强制子 agent 将结果写入 JSON 文件，再由主 agent 汇总成 Excel。
- 增强已有 Excel/半成品 Excel 的增量更新规则。
- 若已有 Excel 中影响因子、JCR 分区、中科院分区等列为空，默认保持为空，不主动补充。
- Web 检索补充字段时要求可靠来源，并禁止使用 Wikipedia 等聚合页作为期刊指标主要来源。
- 保留扫描件 PDF 提醒：当前 OCR 未启用，扫描件或纯图片 PDF 会记录问题并跳过。

## 使用建议

- 一个任务总目录下放一份字段说明书。
- 每个子文件夹代表一个 Excel 任务，里面放对应 PDF。
- 如果有半成品 Excel，可放入对应子文件夹中进行增量更新。
